# Этап 1. Инициация проекта

## Основание для разработки
Задание на рейтинговую работу по дисциплине «Проектная деятельность в ИТ»,
вариант «П»: разработка программы учёта и анализа личных финансов.

## Назначение
Программа предназначена для одного пользователя, который хочет вести учёт
личных доходов и расходов и видеть, на что уходят деньги.

## Цель проекта
Выпустить версию 1.0 консольной программы «Личные финансы».

## Участники
| Роль | Задачи |
|------|--------|
| Руководитель проекта | план, приёмка этапов, выпуск версий |
| Аналитик | требования, техническое задание |
| Разработчик | проектирование и код |
| Тестировщик | тесты, отчёт о тестировании |
| Заказчик (пользователь) | замечания, приёмка результата |
