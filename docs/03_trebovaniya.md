# Этап 2. Анализ требований

## Функциональные требования
- ФТ-1. Добавление операции: дата, тип (доход или расход), категория, сумма, комментарий.
- ФТ-2. Просмотр списка операций.
- ФТ-3. Расчёт баланса: доходы минус расходы.
- ФТ-4. Расходы по категориям с долей каждой категории.
- ФТ-5. Итоги по месяцам: доходы, расходы, остаток.
- ФТ-6. Хранение данных между запусками программы.

## Нефункциональные требования
- НФТ-1. Язык Python 3.9 и выше, только стандартная библиотека.
- НФТ-2. Данные хранятся локально в файле формата JSON.
- НФТ-3. Работа в Windows, macOS и Linux.
- НФТ-4. Суммы хранятся в копейках, чтобы не было ошибок округления.
