# Этап 7. Сопровождение

- Ошибки и пожелания записываются в разделе Issues репозитория.
- Исправление выполняется в отдельной ветке от develop и попадает в main
  только через запрос на слияние (pull request).
- Каждая выпущенная версия отмечается тегом: v1.0, v1.1 и далее.

## План развития
- версия 1.1 — ограничения (бюджеты) по категориям;
- версия 1.2 — выгрузка отчётов в файл CSV.
