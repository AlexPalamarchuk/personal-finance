# Этап 3. Проектирование

## Модули
| Модуль | Назначение |
|--------|-----------|
| finance/models.py | класс Operation — одна операция |
| finance/storage.py | чтение и запись операций в файл JSON |
| finance/analytics.py | баланс, расходы по категориям, итоги по месяцам |
| finance/cli.py | команды пользователя |

## Модель данных
Операция: date (ГГГГ-ММ-ДД), kind (income или expense), category, amount (копейки), note.

## Команды
- add — добавить операцию
- list — показать операции
- balance — показать баланс
- report — расходы по категориям
- months — итоги по месяцам
