# Личные финансы

Учебный проект по дисциплине «Проектная деятельность в ИТ».
Тема: разработка программы учёта и анализа личных финансов.

Программа позволяет записывать доходы и расходы, хранить их в файле
и получать простую аналитику: баланс, расходы по категориям, итоги по месяцам.

## Статус проекта

Проект ведётся по каскадной модели жизненного цикла, каждому этапу
соответствует отдельная ветка репозитория.
